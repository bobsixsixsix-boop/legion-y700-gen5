# Dock 参数取舍（2026-10-22）

- 目标：底部 dock 做成 vivo OriginOS 6 平板桌面 dock 的观感。下面是我们定下的取值和理由，其中尺寸、时长和缓动曲线多数沿用了参考 dock 自己的参数；本文不含厂商的资源、代码、类名或原始数据表。
- 单位：Y700 逻辑 px（横屏 1600×1002，缩放 1.9）。
- 实际生效的数值以代码为准：`y700-shellbar/qml/Dock.qml`、`y700-shellbar/qml/DockButton.qml`；效果图 `design/y700-dock-mockup.html` 的 CSS 与之一致。
- 参考的是 OriginOS **6**。OriginOS 7（2026-09 发布，液态玻璃）的 dock 不在对照范围内；Dock.qml 里的 OS7 玻璃层（亮边、高光、点触光感）是另加的一档。

## 取值

| 项 | 取值 | 说明 |
|---|---|---|
| 图标 | 60 | 平板上 56–62 都合适，取 60 |
| 内边距（四周一致） | 16 | 与图标成比例 |
| 板高 | 92 = 60+2×16 | 图标 + 2×内边距 |
| 图标空隙 | 20 | |
| 板宽 | n×60+(n−1)×20+2×16，居中 | 随图标数伸缩 |
| 最大宽 | 屏宽−2×18 | |
| 底边距 | 18 | |
| 圆角 | 30 | 约为图标圆角的 2 倍 |
| 分隔线 | 2×22，白 60% | 固定区与近期区之间；近期区最多 3 个（Main.qml） |
| 运行指示点 | 6 px 白点，开着窗口的应用才有 | 参考 dock 没有，是我们 2026-11-10 加的：大小和颜色借同一屏上桌面翻页指示器的选中点，放在图标下方 16 px 正中；淡入 250 ms、淡出 200 ms，曲线同增删（Dock.qml 的 AppButton） |
| 描边 / 阴影 | 没有 | 只有填充；OS7 档的 1 px 亮边除外 |
| 按压 | 缩放 0.90；按下 200 ms，抬起 250 ms | 缓动曲线见 DockButton.qml |
| 重排 / 增删 | 250 ms | 缓动曲线见 Dock.qml |

## 材质与动效

- 材质：KWin 模糊打底，桌面上先浅后深两层薄纱，应用内一层灰纱（应用内要比桌面亮一点）；不画阴影、不描边。具体颜色和透明度在 Dock.qml。
- 动效：按压是一次轻微缩小再回弹；图标增删、重排走同一条移动曲线；dock 离场比入场快。应用内 dock（B+ 模式）由底边短滑呼出，4 s 无触碰自动收起（Main.qml）。
